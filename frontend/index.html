Bahdanau Attention Architecture Overview

SOTA Recurrent Translation

Traditional sequence-to-sequence models suffer from the information bottleneck: the entire input sentence must be compressed into a single fixed-length vector before decoding.

Bahdanau (Additive) Attention resolves this by allowing the decoder to dynamically search across all encoder hidden states at each output step, generating an adaptive context vector ct weighted by attention alignment scores.

Active Model Specifications
  • • Encoder: Bidirectional 1-Layer LSTM (Hidden: 256, Emb: 128)
  • • Attention: Bahdanau Additive (Score: vT tanh(Wss + Whh))
  • • Decoder: 1-Layer LSTM (Hidden: 256, Emb: 128)
  • • Source Vocab: 3,544 English tokens
  • • Target Vocab: 6,000 Marathi tokens

Project: ATTENTION X – Theoretical Foundations & Architecture

Technical Whitepaper

1. Background & The Bottleneck Problem

Traditional recurrent sequence-to-sequence networks (Sutskever et al., 2014) compress variable-length input sequences into a single fixed-dimensional bottleneck vector. For longer sentences or languages with divergent grammatical structure (like English SVO to Marathi SOV), this compression causes severe information degradation.

2. Bahdanau (Additive) Attention Formulation

Introduced by Bahdanau, Cho, and Bengio (ICLR 2015), Additive Attention creates dynamic shortcuts between every encoder output and the decoder:

1. Alignment Energy Score:
    et, i = vT • tanh(Ws • st-1 + Wh • hi)

2. Attention Weights (Softmax Normalization):
    αt, i = exp(et, i) / Σk exp(et, k)

3. Dynamic Context Vector:
    ct = Σi αt, i • hi

where st-1 is the previous decoder hidden state, hi is the i-th bidirectional encoder annotation, Ws, Wh are learnable projection matrices, and v is the alignment vector.

3. English to Marathi Linguistic Challenges

  • • Word Order Discrepancy: English follows Subject-Verb-Object (SVO), whereas Marathi is strictly Subject-Object-Verb (SOV). The attention mechanism automatically learns long-range reordering to attend to verbs at the very end of Marathi sentences.
  • • Morphological Richness: Marathi is agglutinative and features rich postpositions (विभक्ती प्रत्यय) attached directly to nouns, demanding fine-grained token-level attention.

4. How the "Click Any Word" Feature Works

When a user clicks on any generated Marathi token in the Attention Lab, the platform queries row t of the actual attention matrix α, identifies the highest-weighted source index i* = argmax(αt), computes the attention entropy H(αt) = -Σ αt,i log2 αt,i, and constructs a clear explanation in both Marathi and English. This provides immediate proof to evaluators and professors that the neural model made a conscious, data-driven alignment decision.
